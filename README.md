# Blinkit Sales Analysis – Power BI

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze Blinkit grocery sales data.

The dashboard provides insights into sales performance, outlet characteristics, product categories, outlet locations, and customer ratings.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Excel

## 📌 Key KPIs

- Total Sales: $1.2M
- Average Sales: $141
- Number of Items: 9K
- Average Rating: 4

## 🔍 Analysis

The dashboard analyzes:

- Sales by Outlet Type
- Sales by Outlet Size
- Sales by Outlet Location
- Sales by Item Type
- Fat Content Analysis
- Outlet Establishment Trends
- Item Visibility
- Average Rating
- Overall Sales Performance

## 📁 Project Files

- `BlinkitAnalysis-project.pbix` – Power BI dashboard
- `BlinkIT Grocery Data.xlsx` – Dataset used for analysis
- `Dashboard.png` – Dashboard screenshot

## 💡 Key Insights

- Supermarket outlets contribute significantly to total sales.
- Tier 3 outlets show strong sales performance compared with other outlet locations.
- Medium-sized outlets contribute a major share of sales.
- Regular-fat products contribute more sales than low-fat products.
- Different item categories show different levels of sales performance.

## 🎯 Conclusion

This dashboard helps analyze Blinkit's sales performance and provides a clear view of product and outlet-level performance using interactive Power BI visualizations.
